# AWS Linux CloudOps Lab

AWS와 Linux 환경에서 클라우드 서버를 직접 구축하고 운영해보기 위한 개인 프로젝트입니다.

## 프로젝트 목표

* AWS EC2 기반 Linux 서버 구축
* SSH를 이용한 원격 서버 접속 및 관리
* Linux 기본 명령어와 시스템 관리 실습
* Nginx를 이용한 웹 서버 구성
* Docker를 이용한 애플리케이션 컨테이너화
* 간단한 장애 상황 재현 및 원인 분석

## 예정 아키텍처

Internet
↓
AWS Security Group
↓
EC2 (Ubuntu Linux)
↓
Nginx
↓
Docker
↓
FastAPI
